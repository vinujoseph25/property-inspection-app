# Property Inspection App

A React Native mobile application prototype for capturing and managing property inspection information.

## Overview

This project demonstrates a mobile-first approach to structured inspection workflows using **React Native** and **Redux**. The application includes reusable form-oriented UI components for collecting inspection data and presenting it consistently across the workflow.

## Technology Stack

- **React Native** 0.60.5
- **React** 16.8.6
- **Redux** 4.x
- **React Redux** 7.x
- **JavaScript / JSX**
- **Jest** for testing
- **ESLint** for code quality

## Key Engineering Areas

- Mobile application development with React Native
- State management with Redux
- Reusable form and input components
- Structured inspection-data capture
- Cross-platform UI development
- Automated testing and linting

## Getting Started

### Prerequisites

Install Node.js and the React Native development prerequisites for your target platform.

### Install dependencies

```bash
npm install
```

### Start the Metro bundler

```bash
npm start
```

Use the standard React Native workflow to launch the application on an Android emulator/device or iOS simulator/device.

## Quality Checks

Run the test suite:

```bash
npm test
```

Run linting:

```bash
npm run lint
```

## Project Status

This is a **legacy React Native project** built with React Native 0.60.5. It is best viewed as an example of mobile application architecture and frontend engineering rather than a current production template.

## Why This Project Matters

The project demonstrates experience applying component-based UI development and predictable state management to a mobile workflow—skills that transfer directly to larger enterprise frontend applications.
